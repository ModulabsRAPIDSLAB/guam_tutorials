    빠른 시작¶

    표 형식 데이터 학습으로 OOF 예측과 테스트 예측을 얻는 최소 경로.

    PyPI guam 은 이 프로젝트의 배포본이 아님

    공개 PyPI의 guam==0.0.3 은 이 저장소의 릴리즈가 아님. pip install guam[gpu] 로 설치 불가. 아래 경로 중 하나를 사용.

    1. 환경¶

    동작 요건은 Linux + NVIDIA CUDA 12(RAPIDS 26.2 계열). GPU가 없는 환경에서도 패키지 import는 가능하나(CPU-import-safe 가드레일) 학습은 불가.

    무료 GPU 환경으로는 Kaggle Notebook(T4) 또는 Colab(T4) 권장.

    소스 체크아웃¶

    git clone https://github.com/ModulabsRAPIDSLAB/GUAM.git
cd GUAM
uv sync --extra gpu --extra dev

    멀티-GPU 포함¶

    uv sync --extra gpu --extra dist --extra dev

    [dist] 는 Dask-CUDA·Dask Distributed 런타임을 추가. [dist] 단독으로는 cuDF·cuML 등 GPU 학습 런타임이 설치되지 않으므로 [gpu] 와 함께 지정 필요.

    2. 첫 학습¶

    필요한 것은 cudf.DataFrame 과 타깃 컬럼명.

    import cudf
from guam.automl.presets import TabularAutoML
from guam.tasks import Task

train_df = cudf.read_csv("train.csv")
test_df = cudf.read_csv("test.csv")

automl = TabularAutoML(Task("binary"), timeout=600)

# OOF 예측(교차검증 결과). roles 로 타깃과 제외 컬럼 지정.
oof = automl.fit_predict(
    train_df,
    roles={"target": "label", "drop": ["id"]},
    verbose=1,
)

pred = automl.predict(test_df)

    fit_predict 내부에서 CudfReader → K-fold → MLAlgo → Blender 자동 조립. 반환 타입은 GUAMDataset 이며 예측은 GPU 잔류.

    결과 추출¶

    probs = pred.data.to_cupy()      # cupy 배열 (GPU 잔류)
print(automl.classes_)           # 예측 코드 → 원본 라벨 (submission 역변환용)

    3. 구성 변경¶

    알고리즘 풀·fold 수·블렌더는 general_params 로 조정.

    automl = TabularAutoML(
    Task("multiclass"),
    timeout=1200,
    general_params={
        "use_algos": ["nn", "xgb"],   # 미지정 시 프리셋 기본 풀
        "n_folds": 5,
        "blender": "nelder_mead",     # 미지정 시 주 메트릭 유형으로 자동 선택
    },
    xgb_params={"n_estimators": 800},
)

    블렌더는 기본값이 안전

    미지정 시 주 메트릭 유형에 따라 자동 선택. 랭킹·proper scoring 지표(AUC, log-loss)는 weighted, argmax 민감 지표(F1-macro 등)는 nelder_mead. 명시 지정은 A/B 측정처럼 의도가 분명한 경우에 한정.

    4. 멀티-GPU¶

    기본값 compute="auto" 의 환경 감지. 가시 GPU가 복수면 Dask-CUDA 경로, 단일이면 기존 경로. 코드 수정 불필요.

    automl = TabularAutoML(Task("binary"))                            # auto (기본값)
automl = TabularAutoML(Task("binary"), compute="single")          # 단일 GPU 강제
automl = TabularAutoML(Task("binary"), compute="dask", n_gpus=4)  # GUAM 관리 클러스터

    기존 Dask 클러스터의 주입도 가능. 이 경우 주입된 Client는 GUAM이 닫지 않음.

    from dask.distributed import Client

automl = TabularAutoML(Task("binary"), compute="dask", dask_client=Client(...))

    dask_client 와 n_gpus 의 동시 지정 불가

    worker topology의 정본이 주입된 Client이기 때문.

    5. 시간 예산¶

    timeout 은 실제 예산. 잔여 예산에 따라 HPO를 축소하고, 다음 유닛의 학습 시간이 부족하면 해당 유닛을 건너뜀. 건너뛴 사실은 은닉 없이 기록.

    automl.fit_predict(train_df, roles={"target": "label"})

print(automl.budget_report_)   # {"timeout":..., "elapsed":..., "utilization":..., "overrun":...}
print(automl.skipped_units_)   # 예산으로 건너뛴 유닛 (사유·잔여·필요 추정)
print(automl.tuning_report_)   # 유닛별 튜닝 수행/생략
